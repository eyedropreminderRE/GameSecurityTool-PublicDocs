# GameSecurityTool — Public Documentation

GameSecurityTool (GST) の公開ドキュメントリポジトリです。

ここでは、GSTのアーキテクチャ、セキュリティ境界、機能仕様、検証方針など、公開対象として選定・確認されたドキュメントを提供します。

## Important status note

These documents describe the project's design, requirements, architecture, and verification models. A document's presence here does not by itself mean that the corresponding feature is implemented, Windows-verified, or released.

Implementation and release status must be determined from the current authoritative project records rather than inferred from publication alone.

## Scope and maintenance

This repository is a publication surface derived from the private GameSecurityTool source repository. Internal development workflow, change-control records, work-management records, personal information, and other non-public material are intentionally excluded.

The public documentation set may be revised as the project evolves. Published design material should not be interpreted as a guarantee of implementation or future release.
