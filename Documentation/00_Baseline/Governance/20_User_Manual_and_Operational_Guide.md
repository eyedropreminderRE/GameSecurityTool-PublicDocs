## 1. ダッシュボードと基本状態 (Dashboard)

GST のダッシュボードは、PC ゲーム環境全体の安全性を一目で確認できるメイン画面です。

* **保護ステータス:** 対象ゲームに対する保護の利用可能性を示します。表示は **🟢 保護中 / 🟡 一部制限あり / 🔴 保護停止** の3段階です。
* **推奨アクション:** 「バックアップが古くなっています」や「孤立したルールがあります」など、より安全な状態を保つために推奨される行動をシステムが提案します。
* **クイックリカバリ (Undo):** 誤ってファイルを隔離してしまった場合など、ダッシュボード上部からワンクリックで復旧レビューを開き、直前の状態への復旧をすばやく開始できます。実データの復元・上書きは、内容を確認し、ユーザーが明示的に承認した後にのみ実行されます。
* **スマート通知抑制 (Smart Do Not Disturb):** 通常のトースト通知はフルスクリーンゲーム中に抑制できます。ただし、保護停止・重大な脅威検知・復旧失敗・重大なユーザー確認要求などのCritical通知は完全には抑制せず、ゲームのフォーカスを奪わない最小表示と未確認状態を残します。

### Normal / Advanced / Expert の使い分け
日常利用では、**ゲーム登録・ゲーム起動・保護状態の確認・セーブバックアップ・問題発生時の復旧**を主な導線とします。個別Firewall ruleの細かな編集、KDF、詳細監査、PC移行、ゲーム本体アーカイブなど専門的な操作はAdvanced/Expert向けです。MOD、Smart IME、Anti-Wiperなどは対象ユーザーに価値が高いため、専門性だけを理由に一律で隠すのではなく、利用目的と影響範囲に応じて表示されます。

### Security Foundation と実行中保護
Security Foundationはユーザー設定から無効化できない安全基盤です。ただし「常時有効」は、GSTが終了していてもFirewallやゲーム監視が動き続けるという意味ではありません。Recovery Host、Recovery Journal、Secure Storage、Integrity Verification等の安全基盤と、GST実行中に提供されるFirewall・ゲーム監視等のRuntime Protectionは別のものとして扱います。OS自動起動は既定OFFです。

## 2. ゲームライブラリ ＆ スマートランチャー (Game Library & Launch Modes)

登録されたゲームを一覧表示し、起動オプションの選択や安全なゲームの追加を行うポータル画面です。

* **ポータブルゲームの安全展開 (Safe Onboarding):**  
  ZIP / 7z / RAR 形式で配布されているフリーゲームや同人ゲームのファイルを、画面上部のドロップエリアへドラッグ＆ドロップするだけで、悪意あるアーカイブ攻撃（Zip Slip 脆弱性）を遮断しながら安全に展開し、メインの `.exe` を自動検出してライブラリへ即座に登録します。
* **2段階の起動オプション:**
  * **▶️ 通常起動 (Standard Launch):**  
    登録された設定（Effective Policy: 通信制御・Web保護等）に準拠して通常通り起動します。Steam 等の公式ゲーム向けです。
  * **🛡️ 厳格モードで起動 (Strict Safe Launch):**  
    外部との通信（インバウンド／アウトバウンド）を対象プロセス単位で一時的に遮断し、Windows Error Reporting によるクラッシュダンプ送信を抑止し、監視を強化した状態で起動します。これは通信・WER・監視を対象としたStrict Launchであり、Windows Sandbox等のプロセス隔離環境を提供するものではありません。
* **ゲーム個別の GST 設定:**  
  ライブラリ画面から直接、そのゲーム専用のファイアウォール通信制御（送信のみ遮断／送受信両方遮断／全許可）や、Web リンク保護の挙動（常に却下など）を簡単にカスタマイズできます。

## 3. インゲーム・オーバーレイ HUD (In-Game Overlay)

フルスクリーンゲームのプレイ中であっても、ゲームを最小化（Alt+Tab）することなく、最前面で安全状態の確認やクイック操作が可能です。

* **非干渉・非侵入設計 (Hookless):** DirectX や Vulkan へのグラフィックフック（プロセス注入）を一切行わず、OS レベルの最前面透過ウィンドウとして描画するため、アンチチートによる誤検知リスクを低減しています。
* **デュアル・トリガー入力:** キーボード（`Shift + F12`）とゲームパッドボタン（Xbox / PS / Switch Pro 等）の両方から、設定変更なしで瞬時にオーバーレイを開くことができます。
* **コントローラー配列の自動適応:** 接続されたコントローラーの製造元（VID）を自動識別し、画面上のボタン案内アイコン（Xbox: A/B/X/Y、PlayStation: ✕/◯/⬜/△、Switch: B/A/Y/X）を最適に切り替えます。
* **ゲーム内クイック操作:** ゲームをプレイしながら「今すぐバックアップ」「直前セーブへのピン留め」「Web リンクの安全なブラウザ選択」がワンタップで行えます。

## 4. ゲームとMODの管理 ＆ 出所追跡 (Game & Mod Provenance)

ゲームフォルダへの予期しない変更や、悪意のある可能性が高い不審ファイルを検知して保護します。

* **未署名 MOD の 3層ハイブリッド診断:** 高額な証明書を持たない未署名 DLL（ReShade, SKSE 等）が追加された場合、勝手に削除せず「プロキシ DLL 構造解析」「ブラウザダウンロード履歴（Zone.Identifier）の確認」「元 ZIP / チェックサムのローカル突合」を実施します。表示は「確認できた情報」「注意すべき兆候」「未確認事項」を中心とし、未署名であることだけで悪性とは扱いません。診断結果だけで安全性や無害性を保証せず、Trust Listへの登録はユーザーが内容を確認して行います。
* **ショートカット (.LNK) 改ざん検知:** ゲームの起動ショートカットが書き換えられ、裏で不審なスクリプトを実行させようとする手口（LotL攻撃）を検知し、起動前に警告を発します。
* **ゲームの登録・ライフサイクル管理:** ゲーム本体をアンインストールしても、GST には「過去のゲーム」として登録が保持され、過去に取得したセーブデータのバックアップ等は継続して保護されます。

## 5. ファイアウォールと通信保護 (Firewall)

ゲームフォルダ内の不審なファイルが、バックグラウンドで勝手にインターネットへ情報を送信するのを防ぎます（Default Outbound Block）。

* **Steam 等のローカル通信免除:** Steam のクラウドセーブや実績同期に必要なローカル通信（127.0.0.1）は原則として免除されるため、ブロックを有効にしても通常のプレイへの影響を極力抑える設計になっています。
* **アンチチートの自動判定と【重要警告】:**
  * **動作仕様:** EAC (Easy Anti-Cheat) や Vanguard などの主要アンチチートが検出されても、検出だけで通信免除を自動適用することはありません。ユーザーが明示的に **Anti-Cheat Compatibility Exception** を有効化した場合に限り、選択した登録ゲーム/実行ファイルについてGSTが作成・所有するFirewallルールの互換性例外を適用できます。第三者のFirewallルールは変更しません。
  * **非干渉境界:** GSTはアンチチートの停止・欺瞞・無効化・回避を行わず、プロセス/DLL注入、メモリ変更、ドライバ操作、DirectX/Vulkan内部フック等を行いません。
  * **第三者結果の非保証:** アンチチートの非検知、接続成功、誤検知回避、アカウント警告・停止・BAN等の結果を保証しません。
  * ⚠️ **【重要警告 ＆ 自己責任について】**  
    オンラインゲーム運営元によるアンチチートのアップデート、未知のセキュリティ仕様、またはツールの動作タイミング等により、意図しない通信遮断やアカウントペナルティ（誤BAN・一時停止）が発生するリスクを完全に排除することは困難です。  
    **オンラインマルチプレイや競技性の高いゲームでの通信保護機能の利用は、必ずご自身の判断と責任において行ってください。**  
    万が一ご不安な場合や重要なマッチをプレイされる際は、本画面から該当ゲームの通信を手動で明示許可（Allow）に設定するか、保護エンジンを一時的に無効（Disabled）にしてプレイすることを強く推奨します。
* **ルールの手動管理:** 特定のゲームや実行ファイルに対する通信許可（Allow）や強制遮断（Block）のルールを手動で細かく追加・削除できます。
* **遮断時の確認と変更:** 通信が遮断された場合は、対象ゲーム・対象実行ファイル・通信方向・適用されているポリシー/ルール・想定される影響を確認できます。一般ユーザーに細かなrule CRUDを要求するのではなく、現在利用できる変更手段を案内します。通信設定や例外変更は `Review → Confirm → Execute` の確認手順を経て適用し、適用後は結果を確認します。

## 6. セーブデータ統合管理ハブ ＆ タイムトラベル (Save Data Hub)

すべてのゲームのセーブデータ状況とストレージ消費を俯瞰し、ランサムウェアや MOD 不具合から大切なセーブデータを保護します。

* **全体ストレージ使用量の可視化:** 各ゲームが消費しているバックアップ容量を棒グラフ等で確認でき、グラフをクリックするだけでそのゲームの詳細管理画面へジャンプできます。
* **全ゲーム一括バックアップ:** 登録されているすべてのゲームの最新セーブデータをワンクリックで一括バックアップできます。
* **安全な一括容量お掃除 (Smart Cleanup):** SSD の空き容量が逼迫した際、ピン留めされた重要セーブや最新世代は厳重に保護したまま、古い通常世代だけを一括安全パージできます。
* **外部保管と復旧可能性:** バックアップは Standard ZIP コンテナとして外部保管・移送しやすい形式を採用しますが、暗号化 payload は GST 固有の Chunked AEAD 形式です。7-Zip / Windows Explorer などの汎用アーカイバだけで暗号化 payload を復号・復元できることは保証されません。GST が利用できない環境でも復旧できることを目的とする場合は、GST互換の独立復旧手段を別途用意する必要があります。
* **ピン留め保護 (Pinning) ＆ タグ管理:** 「ボス戦直前」や「MOD 導入前」などの重要なセーブデータは、ピン留め（📌）やカスタムタグを付与することで、容量制限などによる自動削除の対象から除外されます。
* **セーブ肥大化検知 (Save Bloat Visualizer):** スクリプトの残留バグ等によるセーブデータ容量の急激な肥大化（+50%以上の急増）を容量推移グラフで可視化・警告します。
* **安全な復元 (RescueSnapshot):** 復元を実行する際、現在のセーブデータは自動的に一時退避（RescueSnapshot）されます。復元中に PC の電源が切れる等のトラブルが発生しても、次回起動時に元の状態への自動ロールバック（自己修復）を試み、データ破損のリスクを最大限回避します。
* **汎用 ZIP エクスポート:** 指定したスナップショットを「他の PC への移動用」や「外部保管用」として、平文またはパスワード付き ZIP ファイルで任意フォルダへ書き出せます（※クラウド等の外部ドライブへ保管する場合は暗号化を強く推奨します）。
* **保存先ストレージの設定 ＆ お引越し:** バックアップの保存先フォルダをゲームごとに自由に指定でき、過去のバックアップを大容量 HDD 等へ一括移送することも可能です。

## 7. ゲーム本体アーカイブの復元・保管管理 (Game Environment Archive Management)

セーブデータバックアップ（進行度の保護）とは明確に区別し、**「ゲームフォルダ全体の構造・バージョンを外部保管し、必要な時に直接復元する管理機能」** です。

* **主な用途:**  
  意図しないゲーム本体のアップデート対策、ローカライズ済み環境の保管、旧バージョンへのロールバック、再ダウンロードの回避など。
* **バックアップの作成（ユーザー側の操作）:**  
  本ツールは PC 負荷やメモリ消費を保護するため、ゲーム本体（数十GB〜）の圧縮（作成）機能は持ちません。`[ 📁 ゲーム本体フォルダを開く ]` を押し、公式 7-Zip 等のお好みの外部ツールを使って圧縮し、保管フォルダへ保存してください。
* **アーカイブの復元（GST 内蔵機能）:**  
  GST にアーカイブ保管フォルダを登録しておくことで、配置されたアーカイブ（`.7z`, `.zip`, `.rar`）を自動検出し、**ボタン 1 つでゲームフォルダへ直接ストリーミング展開・復元** を実行します。
* **メモ機能:** 各アーカイブに「公式 v2.12 パッチ適用＋ローカライズ済み」などのメモを付けて管理できます。

## 8. Web リンク保護とクリップボード (Web & Clipboard Privacy)

ゲーム内からブラウザを開く際や、URL をコピーした際のプライバシーを保護します。

* **Query保護 (Strict Query Stripping):** URLの `?` 以降のQuery Stringは既定で完全に破棄します。これは追跡タグだけでなく、機能上必要なパラメータも対象になり得ます。Raw Query値は画面に表示せず、必要に応じて「Queryを破棄したこと」と理由を確認できます。リンクが正常に動作しない場合は、対応するTrusted hostについて既存のQuery AllowlistをReview → Confirmで設定する回復導線を利用できます。
* **オンデマンド・クリップボードサニタイザー:** Discord や Web サイトからコピーした URL について、ユーザーが明示的に操作した時のみ安全化を行う補助画面を提供します（クリップボードの常時監視や自動改変は行いません）。
* **Browser Picker ＆ 常に却下オプション:** リンクを開く際、普段用の Chrome ではなく「匿名モードの Firefox で開く」といったブラウザ選択が可能です。また、ゲームへの没入を妨げられたくない場合は「常に却下（リンクをすべて無視）」に設定することもできます。
* **Punycode / 偽装ドメイン警告:** 公式サイトに酷似させた偽の文字（国際化ドメイン）を用いたフィッシング詐欺サイトへのリンクを検知し、目立つ警告を表示します。

## 9. 隔離と復元 (Quarantine & Recovery)

ウイルススキャン等で「危険」と判定されたファイルは、検知結果と証拠を確認したうえで、ユーザーが隔離を選択した場合に「隔離庫」へ暗号化して封じ込められます。GSTは原則としてユーザー承認なしに自動隔離・自動削除を行いません。

* **チャンク分割暗号化隔離:** 隔離されたファイルは、Windows DPAPI で保護された強力な AES-256 鍵により 64KB チャンク単位で暗号化されるため、誤って実行される危険性を排除します。
