# GST Formal Baseline

本ディレクトリは、GameSecurityTool（GST）の最高権限設計基準を格納するBaseline領域です。物理Markdownは58ファイルありますが、公開対象は個別の公開範囲レビューを通過した文書に限定します。

---

## 権限レベル（Authority Level）

本ディレクトリ内の文書は、全設計・実装・テストにおける**最高権限（Tier 0）**の判断基準です。
下位仕様書（`01_Architecture/`, `modules/`, `02_Features/` 等）と矛盾が生じた場合は、本 Baseline が常に絶対優先されます。

Baseline文書の権威関係と現行性は、各Document Controlおよび正式な権威連鎖に従って確認します。公開文書はSource of Truthではありません。
